## вимоги
- Python 3.8+
- MySQL або MariaDB

## встановлення
   ```
   git clone https://github.com/CrayZeeEeOne/hiv-test.git
   cd hiv-test
   ```
## віртуальне середовище
```
python -m venv venv
```
```
source venv/bin/activate  # Linux/macOS
```
```
venv\Scripts\activate     # Windows
```
## залежності
```
pip install -r requirements.txt
```
## створення бази даних
```
python create_db.py
```
## перевірка роботи
```
python app.py
```
http://localhost:5000
